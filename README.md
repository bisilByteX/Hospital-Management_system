# 🏥 Hospital Management System

A simple and responsive Hospital Management System built using **HTML, CSS, and JavaScript**. This project allows users to admit patients through an online form and stores patient information in the browser using Local Storage.

## 🌐 Live Demo

👉 **[Hospital Management System – Live Demo](https://hospital-management-system-eosin-pi.vercel.app/)**

## ✨ Features

* 🏥 Modern and Responsive User Interface
* 👤 Patient Admission Form
* 📞 Patient Information Management
* 🩺 Illness/Disease Details
* 📅 Admit Date Selection
* 💾 Local Storage Support
* 📱 Mobile Friendly Design
* ✔ Form Validation

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage

## 📋 Patient Details

The system collects the following information:

* Patient Name
* Gender
* Phone Number
* Address
* Illness / Disease
* Admit Date

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or any web browser.
